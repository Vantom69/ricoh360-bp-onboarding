## When to use a project rather than an album

An **album** groups panoramas so you can find and share them.
A **project** adds a **time dimension**: you track how a single site evolves over time.

Typical use cases:

- A **construction site** you document every week.
- A **building** you inspect every quarter.
- An **industrial zone** you monitor across several interventions.

## Create a project

<VideoPlaceholder id="media:projects" />

1. From the web platform, open the **Projects** section.
2. Click **New project**.
3. Name it after the site or project it represents.
4. Confirm.

## Feed your project

On each visit, add the new panoramas to the matching project. The project keeps an automatic **timeline**: you see at a glance how the site changes.

## Use your project over time

After a few visits, the project becomes a real tracking tool:

- **Compare** a panorama from today with one from last month (see [Compare two panoramas](/en/10-exploiter/comparer)).
- **Annotate** a point to revisit on the next site visit.
- **Share** a complete timeline view with a client or partner.
