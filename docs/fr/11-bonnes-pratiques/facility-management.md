# 11C. Facility management et maintenance

<JourneyStep
  number="11C"
  objective="Adopter les bonnes pratiques RICOH360 pour gérer un parc bâtimentaire et documenter vos interventions de maintenance."
  outcome="Vous savez structurer votre documentation FM pour qu'elle reste utile aux équipes terrain et aux décideurs."

## Les 5 bonnes pratiques essentielles

### 1. Documentez les zones techniques et les équipements clés

Définissez les **zones techniques à documenter** (local technique, chaufferie, ascenseurs, salles serveurs) et les **équipements critiques** qui doivent figurer dans votre base de contenus.

### 2. Capturez avant et après chaque intervention

Pour chaque intervention de maintenance :

- **Capturez un panorama avant** l'intervention (état initial)
- **Capturez un panorama après** l'intervention (résultat)
- **Comparez** les deux pour documenter le travail effectué

[Voir comment comparer deux panoramas →](/fr/10-exploiter/comparer)

### 3. Organisez par bâtiment / étage / zone / équipement

Une structure d'organisation typique en FM :

- **Un projet par bâtiment** ou par site
- **Un album par étage** ou par grand pôle technique
- **Un nommage par zone ou équipement** dans les panoramas

C'est ce qui permet à toute l'équipe FM de **retrouver vite** un visuel sur un équipement précis.

### 4. Annotez les actions et les états

Sur chaque panorama, annotez :

- les **interventions réalisées** (« Filtre changé le 15/03 »)
- les **points à surveiller** lors des prochaines visites
- les **anomalies constatées** à traiter

Vos annotations deviennent un **journal de maintenance visuel** consultable par toute l'équipe.

[Voir comment ajouter des annotations →](/fr/10-exploiter/annotations)

### 5. Préservez un historique visuel exploitable

Conservez les panoramas dans le temps — ils constituent une **mémoire visuelle** du parc :

- Pour les futures interventions
- Pour les audits techniques et assurance
- Pour les passations d'équipe ou de prestataire

::: tip
Capturez à intervalle régulier (trimestriel, semestriel) les zones critiques même en l'absence d'intervention. Cela vous donne une base de comparaison toujours fraîche pour détecter une dégradation.
:::
