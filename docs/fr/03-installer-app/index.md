# 3. Installer l'application mobile RICOH360

<JourneyStep
  number="3"
  objective="Installer l'application mobile RICOH360 sur votre smartphone — c'est elle qui fait le lien entre votre caméra et la plateforme web."
  outcome="L'application mobile RICOH360 est installée sur votre smartphone et prête à l'emploi."
>

## Pourquoi installer l'application mobile

L'application mobile RICOH360 joue trois rôles essentiels au quotidien :

<CardGrid cols="3">
  <Card icon="🔗" title="Connecter la caméra">
    Elle relie votre caméra à votre compte et déclenche les captures.
  </Card>
  <Card icon="📤" title="Transférer vos contenus">
    Elle envoie automatiquement vos panoramas vers le Cloud RICOH360.
  </Card>
  <Card icon="👀" title="Vérifier vos prises">
    Elle vous permet de visualiser et de vérifier vos panoramas avant de les partager.
  </Card>
</CardGrid>

## Télécharger l'application

Choisissez votre store selon votre smartphone, puis scannez le QR code ou cliquez sur le lien :

<QRCodePair />

::: tip Compatibilité
L'application est disponible sur iOS (App Store) et Android (Google Play). Mettez votre système à jour pour profiter de la dernière version.
:::

## Au premier lancement

L'application vous demande de vous connecter à votre compte RICOH360 dès le premier démarrage. C'est l'étape suivante de votre parcours.

</JourneyStep>

<SuccessMessage title="Application installée">
Vous pouvez maintenant vous connecter à votre compte RICOH360 et préparer votre première utilisation.
</SuccessMessage>
