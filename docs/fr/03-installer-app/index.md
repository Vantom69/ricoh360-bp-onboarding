# 3. Installer l'application mobile RICOH360

<JourneyStep
  number="3"
  objective="Installer l'application mobile RICOH360 sur votre smartphone — c'est elle qui fait le lien entre votre caméra et la plateforme web."
  outcome="L'application mobile RICOH360 est installée sur votre smartphone et prête à être utilisée."
>

## Pourquoi installer l'application mobile

L'application mobile RICOH360 joue trois rôles essentiels dans votre quotidien :

<CardGrid cols="3">
  <Card icon="🔗" title="Connecter la caméra">
    Elle relie votre caméra à votre compte et déclenche les captures.
  </Card>
  <Card icon="📤" title="Transférer vos contenus">
    Elle envoie automatiquement vos panoramas vers le Cloud RICOH360.
  </Card>
  <Card icon="👀" title="Vérifier vos prises">
    Elle vous permet de visualiser et vérifier vos panoramas avant de les partager.
  </Card>
</CardGrid>

## Télécharger l'application

Choisissez votre store en fonction de votre smartphone et scannez le QR code, ou cliquez sur le lien :

<QRCodePair />

::: tip Compatibilité
L'application est disponible sur iOS (App Store) et Android (Google Play). Vérifiez que votre système est à jour pour bénéficier de la dernière version.
:::

## Une fois installée

L'application vous demandera de vous connecter à votre compte RICOH360 dès le premier lancement. C'est l'étape suivante de votre parcours.

</JourneyStep>
